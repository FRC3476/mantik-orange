### Seeing what the program did

A program that never shows output is hard to trust. `System.out.println` writes a line to the **console** — the text area under the editor on these pages, or the terminal if you run locally.

```java
System.out.println("Hello world!");
System.out.println("Welcome to Java programming!");
```

Each call prints one line, then moves to the next. The text you want to print goes in double quotes inside the parentheses.

### print vs println

`print` stays on the same line. `println` ends the line.

```java
System.out.print("left ");
System.out.print("motor");
System.out.println();
System.out.println("done");
```

That prints:

```
left motor
done
```

### The main method

Java starts in `main`. Copy this wrapper around the print statements. The class name on these pages should stay `Main`.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello from Java!");
    }
}
```

`public`, `static`, `void`, and `String[] args` will get their own lessons. For now they are the required start of a program.

### Statements and comments

Every complete instruction ends with a semicolon. Java is case-sensitive: `System` works, `system` does not.

```java
public class Main {
    public static void main(String[] args) {
        // Single-line comment — Java ignores this
        System.out.println("First line");

        /* Multi-line comment
           for a longer note */
        System.out.println("Second line");
    }
}
```

<RulesBox title="Mistakes that stop a print">

- Forgetting the semicolon
- Typing `printin` instead of `println`
- Missing a `"` at one end of the text
- Writing `system.out.println` (lowercase `s`)

The text inside the parentheses is an **argument** — a value you hand to `println`. It is not a “parameter list” you have to name yet.

</RulesBox>

On a robot, the same call is useful while you test: print a motor power or a sensor reading and watch the console (or the driver station log). You do not need feedforward constants or extra formatters for that.
