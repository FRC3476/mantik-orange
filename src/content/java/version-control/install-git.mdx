### Install Git, then identify yourself

Git must be on the computer before you can commit. After install you set a **name** and **email**. Every commit records those, so the team can see who changed auto.

Use the email on your GitHub account if you have one. GitHub matches commits to you that way.

If this computer cannot install software, ask a mentor for GitHub Desktop on a team laptop, or use a machine that already has Git. Chromebooks and locked lab PCs often cannot run Git locally — use a different computer for this module.

### Check, then install

In a terminal:

```
git --version
```

If you see a version number, skip to configuration.

<StepsBox title="Windows">

1. Download the installer from [git-scm.com](https://git-scm.com/download/win).
2. Run it. Default options are fine for this course. If you see “Git from the command line,” keep that enabled.
3. Close and reopen the terminal. Run `git --version` again.

</StepsBox>

<StepsBox title="macOS">

1. Open Terminal and run `git --version`. macOS may prompt to install developer tools. Accept that, or install Git from [git-scm.com](https://git-scm.com/download/mac).
2. Confirm `git --version` prints a number.

</StepsBox>

<StepsBox title="Linux">

Use your package manager, for example `sudo apt install git` on Debian/Ubuntu. Then `git --version`.

</StepsBox>

### Name and email

These commands set identity for **all** repos on this computer (`--global`):

```
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git config --list
```

`--list` should show the name and email you just set. To set identity for one repo only, leave off `--global` and run the commands inside that repo.

<RulesBox title="HTTPS first">

When you talk to GitHub from school networks, **HTTPS** is usually easier than SSH keys. SSH is optional later. [GitHub and Remote Repositories](/java/github-remotes) covers remotes.

[GitHub Desktop](/java/github-desktop) is a click-based alternative to the terminal. It still uses real Git commits. You can install it after this lesson if you prefer a GUI.

Students with a school `.edu` address can use the [GitHub Student Developer Pack](https://education.github.com/pack) for private repos. That is optional.

</RulesBox>

<ExerciseBox title="Check your setup">

1. Run `git --version`. Write down the version.
2. Run `git config user.name` and `git config user.email`. Confirm they are your name and GitHub email, not empty and not a teammate’s.

</ExerciseBox>
