### Named boxes

A **variable** is a named place that holds a value. You pick a type (what kind of value), a name, and usually a first value.

Programs use variables so you can print, calculate, and later decide — without typing the same number in five places.

```java
int age = 16;
String name = "Robot";
double speed = 12.5;
boolean isActive = true;

System.out.println("Robot name: " + name);
System.out.println("Age: " + age + " months");
System.out.println("Speed: " + speed);
System.out.println("Active: " + isActive);
```

The `+` between a string and a variable **concatenates**: it builds one piece of text. `"Team: " + name` becomes `Team: Robot` if `name` is `"Robot"`.

### Declare, initialize, assign

- **Declare:** `int wheels;` — the box exists, no value yet
- **Initialize:** give it a first value, often on the same line: `int wheels = 4;`
- **Assign:** change it later: `wheels = 6;`

Use a variable only after it has a value. The compiler will stop you if you print a local variable that was never given one.

Java has other numeric types (`long`, `float`). You will rarely need them in these lessons. `String` is text; it is not a primitive, but you use it the same way for now: declare, assign, print.

<RulesBox title="Names">

- Start with a letter: `motorSpeed`, not `2wheels`
- camelCase for more than one word: `maxBattery`
- Do not use Java keywords as names: `class`, `public`, `int`
- Prefer a readable name over a one-letter name, except a loop counter later

`=` **assigns**. It does not compare. Comparing comes in [Conditional Statements](/java/java-conditionals) with `==`.

</RulesBox>

A later lesson covers **scope** (where a name is visible) once you have methods and classes. Until then, declare variables inside `main` and use them there.
