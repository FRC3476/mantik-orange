### Why vision-based pose estimation?

Wheel odometry drifts. Slip, compression, and encoder error accumulate. AprilTags on the field have known poses. When the camera sees them, you get an absolute field measurement you can fuse with odometry.

That measurement is not exact and not always available. Lighting, occlusion, a single distant tag, or a wrong mount transform can all produce a pose you should reject. The next lesson inserts only the measurements that pass the checks on this page.

### AprilTags and the pipeline

An AprilTag is a fiducial marker with a unique ID. FRC fields place tags at documented poses. The vision system finds the tag in the image, solves for camera pose, then applies the robot-to-camera transform to get a robot pose.

Use the field layout that matches the physical field. For 2026 that is welded or AndyMark — the same choice you made in the PhotonVision or Limelight UI.

### One camera reader

Construct **one** `VisionSubsystem` for the software path you chose. Do not register it as a `SubsystemBase`. Construct one `VisionFusion` in `RobotContainer` with the drivetrain and that reader. `VisionFusion.periodic()` is the sole caller of `pollEstimates()`.

`pollEstimates()` owns camera reads, the pose solve, and vendor quality checks. It returns only estimates that pass those checks. `VisionFusion` then applies timestamp checks and calls `drivetrain.addVisionMeasurement`. Phoenix updates odometry on its own thread — do not call an old `updateOdometry()` from robot code.

Two readers will steal frames from each other. Do not also poll from `CommandSwerveDrivetrain` telemetry.

PhotonVision: call `getAllUnreadResults()` once per loop. The queue is destructive and bounded. Process every accepted capture in timestamp order. Do not keep only the newest pose in a multi-frame batch.

Limelight: each poll returns zero or one fresh `PoseEstimate`.

Diagnostic getters read a cache filled during `pollEstimates()`. They must not call `getAllUnreadResults()` or `getBotPoseEstimate_wpiBlue()` again.

`kDefaultField` is whatever WPILib you installed. Name `k2026RebuiltWelded` or `k2026RebuiltAndymark` explicitly so it matches the field and the coprocessor.

Heading-constrained PhotonVision strategies (`addHeadingData`) and Limelight MegaTag2 are later options. This course uses coprocessor MultiTag with a lowest-ambiguity fallback, and MegaTag1.

### Quality policy (both vendors)

Reject before insertion:

- Non-finite x, y, heading, or timestamp
- Pose outside the field plus a 0.5 m margin
- No tags, or tag metadata that does not match the reported tag count
- Single-tag ambiguity below 0 (unknown) or above 0.7
- Single-tag camera-to-tag distance above 3 m

PhotonVision only: inspect Pose3d Z, roll, and pitch before flattening to Pose2d. Limelight `PoseEstimate.pose` is already 2D.

A MultiTag solve is a MultiTag solve. PhotonVision's fallback can still list every visible target in `targetsUsed`. Use `estimate.strategy` and MultiTag `fiducialIDsUsed`, not `targetsUsed.size()`.

These numbers are illustrative. Measure better ones on your robot.

### Complete VisionSubsystem

The class below is the camera reader. `Drive` is in the fusion lesson.

<CodeTab label="PhotonVision" value="photonvision">

```java
package frc.robot.vision;

import edu.wpi.first.apriltag.AprilTagFieldLayout;
import edu.wpi.first.apriltag.AprilTagFields;
import edu.wpi.first.math.geometry.Rotation3d;
import edu.wpi.first.math.geometry.Transform3d;
import edu.wpi.first.math.geometry.Translation3d;
import edu.wpi.first.math.util.Units;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;
import org.photonvision.EstimatedRobotPose;
import org.photonvision.PhotonCamera;
import org.photonvision.PhotonPoseEstimator;
import org.photonvision.PhotonPoseEstimator.PoseStrategy;
import org.photonvision.targeting.PhotonPipelineResult;
import org.photonvision.targeting.PhotonTrackedTarget;

public class VisionSubsystem {
    public static final String kCameraName = "AprilTagCam";
    public static final Transform3d kRobotToCamera =
        new Transform3d(
            new Translation3d(0.32, 0.0, 0.27),
            new Rotation3d(0.0, Units.degreesToRadians(-15.0), 0.0));

    private final PhotonCamera m_camera;
    private final PhotonPoseEstimator m_estimator;
    private final VisionDiagnostics m_diagnostics = new VisionDiagnostics();

    public VisionSubsystem() {
        this(
            new PhotonCamera(kCameraName),
            AprilTagFieldLayout.loadField(AprilTagFields.k2026RebuiltWelded),
            kRobotToCamera);
    }

    public VisionSubsystem(
            PhotonCamera camera, AprilTagFieldLayout tagLayout, Transform3d robotToCamera) {
        m_camera = camera;
        m_estimator = new PhotonPoseEstimator(tagLayout, robotToCamera);
    }

    public boolean isCameraConnected() {
        return m_camera.isConnected();
    }

    /** Call once from VisionFusion.periodic(). Drains the PhotonVision FIFO. */
    public List<VisionEstimate> pollEstimates() {
        List<VisionEstimate> accepted = new ArrayList<>();
        if (!m_camera.isConnected()) {
            markDisconnected(Timer.getFPGATimestamp());
            return accepted;
        }

        List<PhotonPipelineResult> results = m_camera.getAllUnreadResults();
        results.sort((a, b) -> Double.compare(a.getTimestampSeconds(), b.getTimestampSeconds()));

        for (PhotonPipelineResult result : results) {
            estimateFromResult(result).ifPresent(accepted::add);
        }
        if (results.isEmpty()) {
            m_diagnostics.currentValid = false;
        }
        return accepted;
    }

    private Optional<VisionEstimate> estimateFromResult(PhotonPipelineResult result) {
        Optional<EstimatedRobotPose> multi = m_estimator.estimateCoprocMultiTagPose(result);
        boolean multiTag = multi.isPresent();
        Optional<EstimatedRobotPose> solved = multi;
        if (solved.isEmpty()) {
            solved = m_estimator.estimateLowestAmbiguityPose(result);
            multiTag = false;
        }
        if (solved.isEmpty()) {
            reject("no_tags");
            return Optional.empty();
        }

        EstimatedRobotPose estimate = solved.get();
        Optional<String> quality = VisionQuality.rejectNonFinitePose(
            estimate.estimatedPose.toPose2d(), estimate.timestampSeconds);
        if (quality.isEmpty()) {
            quality = VisionQuality.rejectPhotonOrientation(estimate.estimatedPose);
        }
        if (quality.isEmpty()) {
            quality = VisionQuality.rejectField(estimate.estimatedPose.toPose2d());
        }
        if (quality.isPresent()) {
            reject(quality.get());
            return Optional.empty();
        }

        int tagsUsed;
        if (multiTag
                && estimate.strategy == PoseStrategy.MULTI_TAG_PNP_ON_COPROCESSOR
                && result.getMultiTagResult().isPresent()) {
            tagsUsed = result.getMultiTagResult().get().fiducialIDsUsed.size();
            if (tagsUsed < 2) {
                reject("malformed_metadata");
                return Optional.empty();
            }
        } else {
            PhotonTrackedTarget selected = lowestAmbiguityTarget(result.getTargets());
            if (selected == null) {
                reject("malformed_metadata");
                return Optional.empty();
            }
            double distance = selected.getBestCameraToTarget().getTranslation().getNorm();
            Optional<String> single =
                VisionQuality.rejectSingleTag(selected.getPoseAmbiguity(), distance);
            if (single.isPresent()) {
                reject(single.get());
                return Optional.empty();
            }
            tagsUsed = 1;
            multiTag = false;
        }

        return Optional.of(
            new VisionEstimate(
                estimate.estimatedPose.toPose2d(),
                estimate.timestampSeconds,
                multiTag ? VisionEstimate.multiTagStdDevs() : VisionEstimate.singleTagStdDevs(),
                multiTag,
                tagsUsed,
                multiTag ? "multi_tag" : "single_tag"));
    }

    private static PhotonTrackedTarget lowestAmbiguityTarget(
            List<PhotonTrackedTarget> targets) {
        PhotonTrackedTarget best = null;
        double bestAmbiguity = Double.POSITIVE_INFINITY;
        for (PhotonTrackedTarget target : targets) {
            if (target.getFiducialId() < 0) continue;
            double ambiguity = target.getPoseAmbiguity();
            if (ambiguity < 0) continue;
            if (ambiguity < bestAmbiguity) {
                bestAmbiguity = ambiguity;
                best = target;
            }
        }
        return best;
    }

    public VisionDiagnostics getDiagnostics(double nowSeconds) {
        if (m_diagnostics.lastTimestampSeconds != null) {
            m_diagnostics.ageSeconds = nowSeconds - m_diagnostics.lastTimestampSeconds;
            if (m_diagnostics.ageSeconds > 0.5) {
                m_diagnostics.currentValid = false;
            }
        }
        return m_diagnostics;
    }

    public void notifyPoseReset(double nowSeconds) {}

    public void markDisconnected(double nowSeconds) {
        m_diagnostics.connected = false;
        m_diagnostics.currentValid = false;
        m_diagnostics.lastRejectReason = "disconnected";
        m_diagnostics.ageSeconds =
            m_diagnostics.lastTimestampSeconds == null
                ? null
                : nowSeconds - m_diagnostics.lastTimestampSeconds;
    }

    public void recordFusionReject(String reason, double nowSeconds) {
        reject(reason);
    }

    public void recordFusionAccept(VisionEstimate estimate, double nowSeconds) {
        m_diagnostics.acceptedCount += 1;
        m_diagnostics.currentValid = true;
        m_diagnostics.lastTimestampSeconds = estimate.timestampSeconds;
        m_diagnostics.ageSeconds = nowSeconds - estimate.timestampSeconds;
        m_diagnostics.lastRejectReason = "";
        m_diagnostics.solveLabel = estimate.solveLabel;
        m_diagnostics.tagsUsed = estimate.tagsUsed;
        m_diagnostics.connected = true;
    }

    private void reject(String reason) {
        m_diagnostics.rejectedCount += 1;
        m_diagnostics.currentValid = false;
        m_diagnostics.lastRejectReason = reason;
    }
}
```

```java
package frc.robot.vision;

import edu.wpi.first.math.geometry.Pose2d;
import frc.robot.LimelightHelpers;
import frc.robot.LimelightHelpers.PoseEstimate;
import frc.robot.LimelightHelpers.RawFiducial;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;

public class VisionSubsystem {
    public static final String kCameraName = "limelight";

    private final String m_cameraName;
    private final VisionDiagnostics m_diagnostics = new VisionDiagnostics();

    public VisionSubsystem() {
        this(kCameraName);
    }

    public VisionSubsystem(String cameraName) {
        m_cameraName = cameraName;
    }

    public boolean isCameraConnected() {
        return true;
    }

    /** Call once from VisionFusion.periodic(). Zero or one fresh MegaTag1 estimate. */
    public List<VisionEstimate> pollEstimates() {
        List<VisionEstimate> accepted = new ArrayList<>();
        PoseEstimate estimate = LimelightHelpers.getBotPoseEstimate_wpiBlue(m_cameraName);
        if (estimate == null) {
            m_diagnostics.currentValid = false;
            return accepted;
        }
        fromLimelight(estimate).ifPresent(accepted::add);
        return accepted;
    }

    private Optional<VisionEstimate> fromLimelight(PoseEstimate estimate) {
        Pose2d pose = estimate.pose;
        Optional<String> quality =
            VisionQuality.rejectNonFinitePose(pose, estimate.timestampSeconds);
        if (quality.isEmpty()) {
            quality = VisionQuality.rejectField(pose);
        }
        if (quality.isPresent()) {
            reject(quality.get());
            return Optional.empty();
        }

        if (estimate.tagCount <= 0) {
            reject("no_tags");
            return Optional.empty();
        }
        RawFiducial[] fiducials = estimate.rawFiducials;
        if (fiducials == null || fiducials.length != estimate.tagCount) {
            reject("malformed_metadata");
            return Optional.empty();
        }

        boolean multiTag = estimate.tagCount >= 2;
        if (!multiTag) {
            RawFiducial tag = fiducials[0];
            Optional<String> single =
                VisionQuality.rejectSingleTag(tag.ambiguity, tag.distToCamera);
            if (single.isPresent()) {
                reject(single.get());
                return Optional.empty();
            }
        }

        return Optional.of(
            new VisionEstimate(
                pose,
                estimate.timestampSeconds,
                multiTag ? VisionEstimate.multiTagStdDevs() : VisionEstimate.singleTagStdDevs(),
                multiTag,
                estimate.tagCount,
                multiTag ? "multi_tag" : "single_tag"));
    }

    public VisionDiagnostics getDiagnostics(double nowSeconds) {
        if (m_diagnostics.lastTimestampSeconds != null) {
            m_diagnostics.ageSeconds = nowSeconds - m_diagnostics.lastTimestampSeconds;
            if (m_diagnostics.ageSeconds > 0.5) {
                m_diagnostics.currentValid = false;
            }
        }
        return m_diagnostics;
    }

    public void notifyPoseReset(double nowSeconds) {}

    public void markDisconnected(double nowSeconds) {
        m_diagnostics.connected = false;
        m_diagnostics.currentValid = false;
        m_diagnostics.lastRejectReason = "disconnected";
        m_diagnostics.ageSeconds =
            m_diagnostics.lastTimestampSeconds == null
                ? null
                : nowSeconds - m_diagnostics.lastTimestampSeconds;
    }

    public void recordFusionReject(String reason, double nowSeconds) {
        reject(reason);
    }

    public void recordFusionAccept(VisionEstimate estimate, double nowSeconds) {
        m_diagnostics.acceptedCount += 1;
        m_diagnostics.currentValid = true;
        m_diagnostics.lastTimestampSeconds = estimate.timestampSeconds;
        m_diagnostics.ageSeconds = nowSeconds - estimate.timestampSeconds;
        m_diagnostics.lastRejectReason = "";
        m_diagnostics.solveLabel = estimate.solveLabel;
        m_diagnostics.tagsUsed = estimate.tagsUsed;
        m_diagnostics.connected = true;
    }

    private void reject(String reason) {
        m_diagnostics.rejectedCount += 1;
        m_diagnostics.currentValid = false;
        m_diagnostics.lastRejectReason = reason;
    }
}
```

`validPoseEstimate()` on LimelightHelpers only checks that fiducial metadata is present. It is not a quality filter. The checks above are.

Helpers `VisionEstimate`, `VisionQuality`, `VisionDiagnostics`, and `VisionFreshness` are the same classes `Drive` uses in the fusion lesson. Keep their constructors and method names identical across vendors. `DriveHardware` is the adapter over your existing gyro and module positions (FL, FR, BL, BR).
