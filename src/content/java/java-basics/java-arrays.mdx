### A numbered row of slots

An **array** holds several values of the **same type** in a fixed number of slots. Use one when you already know how many values you have — four motor powers, six sensor readings — and that count will not grow.

Each slot has an **index**. The first slot is `0`. The last slot is `length - 1`.

```java
int[] powerLevels = {25, 50, 75, 100};

System.out.println(powerLevels[0]);      // 25
System.out.println(powerLevels[3]);      // 100
System.out.println(powerLevels.length);  // 4
```

`powerLevels.length` is the number of slots. It is a field, not a method — no parentheses.

### Creating an array

Two common forms:

```java
int[] sensorReadings = new int[5];
sensorReadings[0] = 100;
sensorReadings[4] = 95;

int[] alreadyFilled = {4, 8, 15};
```

`new int[5]` makes five slots. Each starts at `0`. A `String[]` of the same kind starts with `null` in every slot — you will use that after [Java Objects](/java/java-objects).

You cannot add a sixth slot later. If you need a list that grows, that is [ArrayLists](/java/java-ds-arraylists) in Data Structures.

### Walking the slots

To visit every index, repeat with a **for** loop. Loops are the next module; this pattern is how you print or add the values. `i` starts at `0` and stops before `length`, so you never walk off the end.

```java
int[] values = {4, 8, 15};
int sum = 0;

System.out.println("Length: " + values.length);
for (int i = 0; i < values.length; i++) {
    System.out.println(values[i]);
    sum = sum + values[i];
}
System.out.println("Sum: " + sum);
```

<RulesBox title="Array mistakes">

- Index `5` on an array of length 5 — valid indexes are `0` through `4`. That crash is `ArrayIndexOutOfBoundsException`
- Mixing types in one array — an `int[]` cannot hold a `String`
- Using `.length()` — that is for `String`. Arrays use `.length` with no `()`
- Forgetting that a brand-new `int[]` is filled with zeros, not “empty”

</RulesBox>

A `String[]` works the same way as `int[]`:

```java
String[] systems = {"Drive", "Arm", "Intake"};
System.out.println(systems[1]);  // Arm
```

Putting your own classes in an array waits until Object-Oriented Programming. Why arrays are fast to index, and when to pick something else, is [Arrays and Their Trade-offs](/java/java-ds-arrays).
