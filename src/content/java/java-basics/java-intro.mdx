### What Java is

Java is a programming language. You write instructions. The computer (or the robot) follows them, one step at a time.

A **program** is a list of those instructions saved in a file. Java programs are made of **classes**. Every program you write in this course starts in a method named `main`. When you run the program, Java looks for `main` and starts there.

You do not need to memorize what `public`, `static`, and `void` mean yet. Copy the structure. Later lessons name each word.

### Why robotics teams use Java

FTC robot code is Java. FRC robot code is Java. Mentors, sample projects, and vendor libraries are written for this language, so the team shares one set of skills.

This course uses small examples you can run in the browser. When you move to robot code, the language is the same. The libraries change (OnBot Java or Android Studio for FTC, WPILib VS Code for FRC).

The [course map](/java) lists every module. Come back to it when you need to find a topic. This page is the first lesson.

### Your first program

This program prints one line, then stops.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello, Java!");
    }
}
```

Click **Run**. The console below the editor should show:

```
Hello, Java!
```

`System.out.println` sends a line of text to that console. The next lesson, [Java Printing](/java/java-printing), is about this command in more detail.

The class is named `Main` so it matches the file the playground compiles. Keep that name on these pages.

<RulesBox title="If Run does nothing">

The first Run on a page downloads a Java engine. That can take a moment. After it loads, later clicks are faster.

If you cannot install a JDK on this computer, stay in the browser. [Setting Up Java Locally](/java/java-setup) is the next lesson if you want `javac` on your own machine.

</RulesBox>
