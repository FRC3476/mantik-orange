### Why install Java on your computer

These lessons let you Run code in the browser. That is enough to learn the language.

A local install is useful when you want a debugger, faster reruns, or a project that is more than one file. Robot projects (Android Studio, WPILib VS Code) install their own JDK. You still benefit from knowing `javac` and `java` on the command line.

If you cannot install software — a locked school machine is common — skip this lesson and keep using the in-page Run button. That is a real option, not a lesser one.

### Installing a JDK

You need a **Java Development Kit** (JDK), version 17 or newer. A JDK includes the compiler (`javac`). A JRE is only the runtime (`java`) and is not enough to compile.

<StepsBox title="Install steps">

1. Download a JDK. [Eclipse Temurin](https://adoptium.net/) has no license prompts. Oracle's JDK also works.
2. Run the installer. On Windows, accept the option to add Java to `PATH` if the installer offers it.
3. Open a **new** terminal and check:

```
javac --version
java --version
```

Both should print 17 or higher. If `java` works and `javac` is missing, you installed a JRE instead of a JDK.

</StepsBox>

### Compile and run a small program

Save this as `Main.java`. The class name and the file name must match.

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello from this computer");
    }
}
```

In that folder:

```
javac Main.java
java Main
```

You should see `Hello from this computer`.

`javac` writes `Main.class`. `java Main` runs that class (no `.class` in the command).

On JDK 11 and newer you can skip the compile step for a single file while you iterate:

```
java Main.java
```

<RulesBox title="Common setup mistakes">

- Class `Main` in a file named something else — the compiler will refuse it
- Running `java Main.java` on a very old JDK — use `javac` then `java Main`
- `javac` not found — JDK not on `PATH`, or a JRE was installed. Open a new terminal after install

</RulesBox>

### Robot projects use a different installer

This lesson is the language JDK, not the FTC or FRC project.

- FTC: [OnBot Java](/ftc/onbot-java-setup) in the browser, or [Android Studio](/ftc/android-studio-setup) for the full SDK
- FRC: [WPILib VS Code](/frc/environment-setup)

Those tools bundle a JDK. You still use the same Java you are learning here.

### Programming contests (optional)

Competitive programming pages in this site use the same local JDK. The extra habit is feeding a file into the program instead of typing input each run:

```
java Main < in.txt
```

Name the class `Main`. Put sample input in `in.txt`. Reading input (Scanner or `BufferedReader`) is taught later. If you are here only for contests, continue with [Reading Input Fast](/comp/cp-fast-io).

<ExerciseBox title="Verify the install">

1. Create a folder with `Main.java` containing the Hello program above.
2. Run `javac Main.java`, then `java Main`. Confirm the line prints.
3. Change the quoted text, compile again, and run. Confirm the new line prints.

If you already know how to read `System.in`, optional extra: write a program that reads one integer and prints twice that value, put `21` in `in.txt`, and run `java Main < in.txt`. You should see `42`.

</ExerciseBox>
