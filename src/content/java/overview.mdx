### Java for robotics teams

This course teaches Java from the first program onward. You do not need prior programming experience.

FTC and FRC robot code is written in Java. The same language works for both programs, so what you learn here carries into OnBot Java, Android Studio, and WPILib.

<RulesBox title="Why Java on a robotics team">

- FTC and FRC both use Java for robot code
- The ideas (variables, methods, classes) show up in every subsystem you write
- You can practice in the browser on these pages, then use the same language in your team project

</RulesBox>

### How the course is organized

Ten modules. Complete them in order unless a later page says it is optional.

- **Java Basics:** Printing, variables, types, calculations, and arrays
- **Programming Logic:** Decisions with `if`, reusable methods, and handling errors
- **Loops and Iteration:** Repeating work with `while` and `for`
- **Object-Oriented Programming:** Classes, objects, references, inheritance, interfaces
- **Data Structures:** Choosing how to store data, and what each choice is fast or slow at
- **Common Algorithms:** Recursion, searching, sorting, and graph search
- **Functions as Data:** Passing behavior as a value (lambdas and related types)
- **Design Patterns:** Named structures you will see in WPILib and team code
- **Concurrency and Multithreading:** Extra threads — optional later, and easy to misuse on a robot
- **Version Control with Git & GitHub:** History, branches, and sharing code with your team

Later modules (algorithms after searching, design patterns, concurrency) are stretch. They stay in the sidebar so you can return to them. You do not need them to write a first teleop.

Git sits last in this list on purpose. Jump to [Introduction to Version Control](/java/intro-version-control) as soon as two people share a robot repo. You do not need to finish concurrency first.

### How to use a lesson

1. Read the idea, then the short example.
2. Click **Run** on examples to see output. Click **Edit** if you want to change them.
3. Complete the playground Check when a lesson has one.
4. Use Try It Yourself for extra practice. Show Answers only after you have tried.

Each Java lesson builds on the ones before it. If a page uses a word you do not know, go back one lesson rather than skipping ahead.

<RulesBox title="What you need">

- No prior programming experience
- A computer and a web browser
- Time to type the examples, not only read them

If you cannot install software on a school machine, use the in-page Run button. Local install is covered in [Setting Up Java Locally](/java/java-setup) and is optional for the first lessons.

</RulesBox>
